# Among8

Мобильная игра на интуицию: выбери процент на поле из 100 клеток и сравни его с данными. Соло или дуэль по ссылке, два набора по 10 вопросов, 15 секунд на ответ.

- Сайт: https://among8-duel.alinachandel.chatgpt.site/
- GitHub Pages: https://alinachandel-max.github.io/Among8/
- Источники и определения: [SOURCES.md](SOURCES.md).

## Первый вход и управление

При первом визите — один пробный вопрос без таймера, баллов и обращения к серверу. Можно пропустить; повтор доступен на экране выбора. Прохождение запоминается локально. Приглашение друга сохраняется после пробного вопроса.

Выбери персонажа: галочка и «Ты — Кваки» показывают выбор. В дуэли персонаж друга занят. Выбери набор 1 или 2; друг наследует набор хозяина комнаты. Имена — только имена персонажей.

Поле содержит 100 клеток. Тап или свайп выбирает процент; кнопки 0/100 и +/− уточняют выбор. Клавиатура: стрелки ±1, PageUp/PageDown ±10, Home/End 0/100, Enter отправляет. Кнопка «Ответить: 37%» фиксирует выбор. Если не отправить до конца 15 секунд, ответ пропущен и поле очищается. Ноль — полноценный ответ.

После ответа позиции всегда относительно смотрящего: «Ты» фиолетовым, «Друг» коралловым, «Реальность» зелёным. Текст и формы дублируют цвета. Заполнение остаётся своим ответом; маркеры показывают обе догадки и реальное значение. Эмодзи видны только в выбранных клетках и ограничены их размером. Вопрос и существенная область/возраст видны сразу; определения, год, правила, объяснение факта и источник — в «Инфо».

В дуэли следующий вопрос начинается после готовности обоих. Финальный результат каждый открывает независимо; у друга сохраняется последний ответ до собственного нажатия. Реванш требует согласия обоих.

## Баллы

Ошибка в процентных пунктах: 0–2 → 100; 3–5 → 80; 6–10 → 60; 11–15 → 40; 16–20 → 20; больше 20 → 0. Максимум 1000. Скорость не даёт бонуса. Пропуск даёт 0, средняя ошибка считается по отправленным ответам.

## Сеть и хранение

Worker + D1/SQLite; локально тот же обработчик через Node.js. Дедлайн серверный, перезагрузка не добавляет времени. Состояние обновляется примерно раз в 850 мс, в фоновой вкладке реже. Ответ друга и правильное значение скрыты до раскрытия. Сервер проверяет фазу, роль, диапазон, номер вопроса и дедлайн. Условные SQL-обновления защищают места и счёт от гонок.

Анонимный токен из 256 случайных битов хранится в localStorage, в базе — SHA-256. Приглашение содержит код комнаты без токена. Комната недоступна через 24 часа, очистка выполняется при создании следующих комнат. Для лимитов создаются временные хэши IP, сырой IP не сохраняется в игровых таблицах.

При неудачном выходе сессия сохраняется и можно повторить действие. Недействительная сессия очищается с видимой кнопкой новой игры. Выход из текущей дуэли требует короткого подтверждения, затем закрывает комнату для обоих. Ссылка на логотип выполняет то же действие.

История последнего вопроса содержит `finalSeen` отдельно от голосов за реванш. Это позволяет каждому смотреть финал самостоятельно без миграции схемы. Старые вопросы сохранены с `archived: true` для уже открытых комнат; новые игры используют ровно 20 активных вопросов, две десятки.

Web Share при наличии, затем clipboard, затем выделяемое текстовое поле. Звуки включаются после действия пользователя; выключатель сохраняется локально. Сигнал разочарования: все ответившие игроки дальше 10 пунктов при отсутствии пропусков. Пропуск получает нейтральный сигнал. Reduced motion поддерживается, WebGL имеет запасное отображение.

## Локальный запуск и сборка

Нужен Node.js 24+ со встроенным `node:sqlite`:

```sh
node scripts/dev.mjs
```

Открыть http://127.0.0.1:8082. Локальная база `development.sqlite`, миграции применяются автоматически. Production-миграциями управляет Sites.

```sh
node scripts/build.mjs
node --test tests/server.test.mjs
PLAYWRIGHT_MODULE=/path/to/playwright node tests/browser.cjs
```

Сборка создаёт `dist/server/index.js`, статические файлы, метаданные Sites, миграции и `docs/` для GitHub Pages. Не править `docs/` вручную. Для схемы используются зафиксированные Drizzle dev-зависимости; новые пакеты при этих изменениях не добавлялись.

Браузерный QA: практика, 20 активных вопросов, две независимые сессии, мобильные и desktop размеры, тайм-аут, ноль, роли, источники, независимый финал, реванш, выход без сети, просроченная комната, fallback обмена. Серверные тесты проверяют гонки, безопасность ответов, scoring и совместимость финала старых комнат.

## Ограничения

Это дружеская игра, а не защищённый турнир: вопросы опубликованы в репозитории. Повтор проверяет и память. Данные зафиксированы по указанным годам, часть фактов относится к опросам США; они явно обозначены. Нативные эмодзи выглядят по-разному на разных ОС. Для аппаратной производительности, VoiceOver/TalkBack и понимания детьми требуется отдельная проверка на реальных телефонах.

Нет аккаунтов, профилей, leaderboard, fake player statistics, рекламы или аналитики игроков. Шрифт Manrope — SIL OFL 1.1; персонажи — собственная геометрия, звуки синтезируются локально.
